# CV_CascadeClassifier    
       
Редактирование изображения с помощью CV и каскадов Хаара.       

**Задача:**     
Обнаружение на фото лица и глаз, на лиицо наложить размытие(не включая глаза), глаза закрыть картинкой очков.    
     
**Что сделано:**    
С помощью каскадов Хаара на фото актера Хью Джекмана обнаружено лицо и на фрагмете 'лицо' онаружены глаза. Лицо размыто с помощью cv2.GaussianBlur(). По координатам глаз наложена картинка очков       
     
**Использованные технологии:**       
CV       
      
**Результаты**     
Лицо выделено овалом, глаза кругом. Лицо размыто, картинка лица полностью закрывает глаза.
